# Don Rulo - Prototipo de Rediseño

Este es un prototipo web responsive para el restaurante **Don Rulo**, ubicado en Trujillo, Perú.

## 🎯 Objetivo

Crear una propuesta de rediseño de la página web enfocada en solucionar un problema importante de usabilidad: los usuarios no pueden consultar fácilmente una carta digital con los platos y sus precios antes de realizar un pedido.

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Diseño responsive
- Código organizado y fácil de mantener

## 📱 Diseño Responsive

- **Escritorio**: 1440 px
- **Móvil**: 390 px

## ✨ Características

1. **Encabezado** con identidad visual de Don Rulo y navegación sencilla
2. **Sección principal** con presentación del restaurante y botón para consultar la carta
3. **Carta digital** organizada por categorías (Entradas, Platos Principales, Bebidas, Postres)
4. **Tarjetas de productos** con imágenes, nombres, descripciones y precios de ejemplo
5. **Sección de sedes** con información de contacto
6. **Botón visible** para realizar pedidos mediante WhatsApp
7. **Pie de página** con información del restaurante

## 🎨 Experiencia de Usuario

- Jerarquía visual clara
- Navegación intuitiva
- Contraste adecuado y textos legibles
- Botones fáciles de identificar y utilizar
- Diseño adaptable a dispositivos móviles
- Sin elementos innecesarios

## ⚠️ Importante

- Los precios mostrados son **datos de ejemplo**, no son precios reales de Don Rulo
- Las direcciones, teléfonos y enlaces son **datos demostrativos**
- Este es un **prototipo de rediseño**, no es el sitio oficial de Don Rulo
- No se debe modificar la página web real de Don Rulo

## 📁 Estructura del Proyecto

```
don-rulo-redesign/
├── index.html      # Estructura HTML principal
├── styles.css      # Estilos CSS con diseño responsive
├── script.js       # Funcionalidad JavaScript
└── README.md       # Documentación del proyecto
```

## 🚀 Cómo Usar

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. Para ver el diseño responsive, utiliza las herramientas de desarrollador de tu navegador

## 📐 Breakpoints

- **Mobile**: ≤ 480px (390px target)
- **Tablet**: 481px - 1024px
- **Desktop**: ≥ 1025px (1440px target)

## 🔧 Funcionalidades JavaScript

- Menú móvil responsive
- Filtrado de categorías en la carta
- Botones de pedido individual por WhatsApp
- Smooth scroll para navegación
- Animaciones de entrada al hacer scroll
- Cambio de estilo del header al hacer scroll
